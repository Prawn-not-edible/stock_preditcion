# Git 工作流

1. 确认当前在目标仓库 `main`，先检查 `git status`。
2. 完成一个有意义的阶段并运行该阶段必要的离线检查。
3. 检查差异与文件大小，只暂存本阶段相关文件。
4. 使用清楚的提交说明创建 commit。
5. 推送前执行 `git fetch origin` 并检查远程变化；如有变化，先正常合并或变基，绝不强制推送或重写历史。
6. 推送 `git push origin main` 并确认远程 SHA。
7. 原始 BaoStock 行情在公开分发许可确认前只保存在本地；不得因此删除本地文件。

不得提交凭据、私钥、虚拟环境、模型权重或大型缓存。代码、配置、处理后数据、文档和正式预测 CSV 纳入版本管理。
